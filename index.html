NESH Store Item Order

Pick which item shows first in the customer app's merged NESH Store groceries catalog. This only reorders items in that merged view — it doesn't touch any shop's own menu, price, or availability.

NESH Store Sections

Group your existing groceries shops into sections (e.g. Supermarket, Chicken Store). Pick a section, add a stock item, and it's added to every shop in that section.

Add stock item to a section — only the item itself (name, photo, unit) is added, at ₹0 and marked unavailable. Each shop sets its own price and marks it available from its own Stock screen. A shop that already has the same item (same name and unit) is skipped.

Bulk import stock — Excel/CSV with Name, Discription (optional), Unit (optional), Photo link (optional). Adds every row to every shop in the section picked above — same ₹0/unavailable rule, and a shop that already has a row's item (name + unit) is skipped for that row only.

Bulk upload photos — matches each photo's filename to an item name and attaches it to every matching item across every shop in the section picked above. Unmatched photos are downloaded as photo-links.csv for manual matching.

Push App Update

"Push Update" replaces the app's code (app_config/html) for every restaurant partner automatically the next time they open or refresh it. "View Current Code" loads the currently-live pushed code into the box below so you can inspect or edit it before re-pushing. "Delete Pushed Update" removes app_config/html entirely (partners then keep using whatever copy of the app they already have loaded/cached, until you push again) — existing restaurant data (menu, orders, gpay, etc. under restaurants/*) is stored separately and is never touched by any of these actions.

Go Series

Set a delivery charge (base fee + per-km rate), a platform fee, and a per-item profit amount here that apply ONLY to shops you add to the Go Series list below. The profit amount is added straight into each item's price in the customer app (it shows up as the price itself, not a separate line). Every other shop keeps using its own Delivery Charges, item prices, and the app-wide platform fee, unaffected.

Free delivery — orders whose item total is at least this ₹ amount get no delivery charge (customers see it struck out and marked FREE). 0 = off. Applies to NESH Store and every Go Series shop.

Free delivery by distance — deliveries shorter than this many km (shop to the customer's pin) are free. 0 = off. Works alongside the amount above: an order is free if EITHER one is met. For NESH Store the distance is measured from the shop that would fulfil that cart.

Go Series Shops

Every Groceries shop is in Go Series automatically (no shop-set delivery charge). Other shops added here use the Go Series charge above instead of their own Delivery Charges — everything else about the shop (menu, orders, delivery-boy assignment) works exactly as before.

🛒 NESH Store — Groceries Stock

Let this shop add its own stock — when ON, this shop can add, bulk-import, and re-photo its own items from its own Stock screen (same as Hotel/Other Shop partners), on top of items you add below. When OFF (default for groceries), only you can add new stock items for this shop.

Item price & availability — set any item's price for this shop, and mark it unavailable (hidden from customers) or available again, without needing the shop's login. For gram/kg items the price is the rate per gram/kg.

Add item — for groceries partners: the operator only adds the stock item itself (name, photo, unit) to this shop's menu. No price is set here — the shop sets its own price (and marks it available) from its own Stock screen. The customer-facing price is automatically the highest price any shop charges for that item.

Added items start priced at ₹0 and marked unavailable, so they never show to customers until the shop opens its Stock screen, sets a real price, and marks the item available.

Bulk import stock — Excel/CSV with Name, Discription, Price, Unit (optional), Photo link (optional). Adds items to this shop's menu.

Bulk upload photos — matches each photo's filename to a stock item by name (same as the shop's own uploader) and attaches it directly. Unmatched photos are downloaded as photo-links.csv for manual matching.

Export stock — downloads this shop's full stock as an Excel file, in the same column format (Name, Discription, Price, Unit, Photo) the Bulk import above expects.

Export photos — downloads every stock item's uploaded photo as a .zip, each file named after the item (e.g. "Chicken Biryani.jpg"). Only fetches the photos themselves (from Cloudinary), not the shop's database records — doesn't add to Firebase download usage.

Clear all stock — permanently deletes every stock item for this shop. Export first if you want a backup. Confirming requires this shop's own login (username + password), plus a final confirmation.
